# 業務規則

## 單據編號

格式為 `前綴 + 年月 + 四位流水號`,例如 `PO2026030007`。

| 前綴 | 單據 |
| --- | --- |
| PO | 採購單 |
| SO | 銷售單 |
| INV | 應收帳款 |
| BIL | 應付帳款 |
| PAY | 收付款 |
| JV | 傳票 |
| EMP | 員工工號 |

## 採購單狀態

```
DRAFT -> APPROVED -> PARTIALLY_RECEIVED -> RECEIVED
   \         \
    +---------+--> CANCELLED
```

- 只有草稿可以修改
- 核准後才能收貨
- 已有收貨紀錄不可取消
- 收貨數量不可超過未收數量

## 銷售單狀態

```
DRAFT -> CONFIRMED -> PARTIALLY_SHIPPED -> SHIPPED
   \         \
    +---------+--> CANCELLED
```

- 確認時檢查客戶信用額度: 未收帳款加本單金額不可超過額度 (額度為 0 表示不限)
- 出貨庫存不足時整筆拒絕

## 成本計算

採用移動平均法。每次採購入庫:

```
新成本 = (現有數量 × 現有成本 + 入庫數量 × 入庫單價) ÷ (現有數量 + 入庫數量)
```

銷貨成本以出貨當下的商品成本計算。
