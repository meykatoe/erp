# 業務規則

## 單據編號

格式為 `前綴 + 年月 + 四位流水號`,例如 `PO2026030007`。

| 前綴 | 單據 |
| --- | --- |
| PO | 採購單 |
| SO | 銷售單 |
| INV | 應收帳款 |
| BIL | 應付帳款 |
| PAY | 收付款 |
| JV | 傳票 |
| EMP | 員工工號 |

## 採購單狀態

```
DRAFT -> APPROVED -> PARTIALLY_RECEIVED -> RECEIVED
   \         \
    +---------+--> CANCELLED
```

- 只有草稿可以修改
- 核准後才能收貨
- 已有收貨紀錄不可取消
- 收貨數量不可超過未收數量
