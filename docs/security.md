# 資安說明

## 已實作

- 密碼以 bcrypt 雜湊,不可逆
- JWT 憑證預設 8 小時過期
- 所有端點預設需登入,另以權限字串逐一控管
- 登入端點限流每分鐘 10 次,全域每分鐘 300 次
- 輸入以白名單驗證,未知欄位直接拒絕
- Prisma 參數化查詢,無字串拼接 SQL
- Helmet 安全標頭,Nginx 補上 X-Frame-Options 與 nosniff
- 稽核紀錄記錄所有寫入請求,密碼欄位遮蔽
- 正式環境缺少 `ADMIN_PASSWORD`、`JWT_SECRET` 時拒絕啟動
- 正式環境關閉 Swagger

## 上線前檢查

- [ ] 三個必填密鑰皆為長隨機字串,且未提交至版本控制
- [ ] 在前方加上 HTTPS
- [ ] 資料庫連接埠不對外開放 (compose 預設未對外)
- [ ] 設定 `CORS_ORIGIN` 為實際網域,若前後端同網域可留空
- [ ] 啟用每日備份並完成一次還原演練
- [ ] 初次登入後立即修改管理員密碼

## 已知限制

- 權限寫入 JWT,角色變更需重新登入才生效; 停用使用者後既有憑證到期前仍可使用
- 尚未提供雙因素驗證
- 憑證存於瀏覽器 localStorage,需搭配嚴格的內容安全政策與前端依賴審查

## 通報

發現安全問題請直接聯絡專案維護者,勿公開於議題追蹤。
